云课堂是学海/智通云体系里的在线课堂模块。这里整理一些日常使用中比较顺手的小技巧，按场景分节。

## 搜索

右上角的搜索框支持按文件名查找上课文件，也支持正则表达式（详见 [已知行为记录](/docs/known-behaviors) 与 [XHPE-1001](/tracker/XHPE-1001)）。

```text
# 普通搜索：直接输入关键词
期中复习

# 正则搜索：输入 . 可列出全部文件
.
```

## 作业

作业列表按提交状态分组，未交、已交、已批改一眼可辨。查看作业详情时，如果配图加载不出来，可以退出重进（见 [XHPE-1002](/tracker/XHPE-1002)）。

- 提交前先检查附件是否上传完整
- 批改结果通常在老师发布后一段时间内更新
- 有疑问的题目可以截图留档，方便后续核对

## 错题本

错题本会自动收集做错的题目，方便考前集中复习。建议：

1. 定期整理，把重复出错的题目标记出来
2. 结合解析理解错因，而不是只记答案
3. 考前按章节过一遍，查漏补缺

> 提示：错题本里的题目来自历史作答记录，如果发现缺题，多半是当时作答未同步，可尝试重新进入该章节。

## 小结

云课堂的功能不算复杂，但搜索、作业、错题本三个入口配合使用，能省下不少来回切换的时间。遇到异常行为，欢迎到 [Xuehai Feature Tracker](/tracker/) 提交反馈。
