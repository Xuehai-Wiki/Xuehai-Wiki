本文用于演示「完全涂黑」模式。在你输入本文密码之前,标题、简介、摘要与正文全部显示为「█」,侧栏、文档首页卡片与反向链接里同样看不到任何信息。

## 演示密码

本文的演示密码是 `demo`。

## 各类内容都会被涂黑

普通段落文字、**加粗**、*斜体*、[一个外链](https://example.com/)、行内代码 `code`,以及下面的小节标题。

- 列表项一
- 列表项二
  - 嵌套列表项

| 表头一 | 表头二 |
| --- | --- |
| 单元格 | 单元格 |

> 引用块里的文字同样会被涂黑。

```js
// 代码块也会被逐段涂黑,解锁后恢复语法高亮
console.log('解锁后这段注释会恢复');
```

解锁成功后,本页所有内容应当原样恢复,包括标题、简介与本段文字。
