# XHPE 说明

## 什么是 XHPE
XHPE是学海特性(bug)追踪器使用的特性记录单位，一个XHPE对应一个bug

## XHPE各属性的含义

一个XHPE即 `src/content/tracker/` 下的一个 `.md` 文件，属性写在前置元数据（frontmatter）中，正文为详细描述。各属性含义如下：

### 编号
`XHPE-xxxx(.md)`，从 1001 开始编号，文件名即其编号。

### Type
`Feature` 或 `Bug`，视其有用还是没用。

### Status
对该条目确信程度的评估，取值：

| 取值 | 含义 |
| --- | --- |
| `MIGHT` | 可能存在，无法稳定复现 |
| `PARTLY VALID` | 视条件有效，需要特定学校/条件 |
| `VALID` | 有效，确认通用 |
| `CHANGED` | 被改动，学海修改过实现，行为已变化 |
| `FIXED` | 被修复 |


### APP Name
特性所在的应用名称，如 云课堂 / 智通平台。

### APP Version
特性所在应用的版本号，即确认该特性存在的应用版本。

### XHCS
1-5 的整数，意为学海草台班子评分，根据此 feature 的效果和触发难度评分。

### Title
不含应用名的概括。

### Reporter
提交者，留空代表匿名提交。

### Desc
特性的详细描述（如何复现？效果是什么？），可多行。

## 示例

以 XHPE-1001 为例，一个完整的记录文件长这样：

```markdown
---
type: 'Feature'
status: 'VALID'
appName: '云课堂'
appVersion: 'v6.16.18.20260409(1213)'
xhcs: 2
title: '搜索-上课文件中支持正则表达式'
---

云课堂右上角搜索-上课文件中实际上支持特定正则表达式搜索。

比如输入 `.` 可搜到全部文件。
```
