# 智通平台

## 基本信息

智通平台在平板中起到桌面的作用。其功能包括：

- 处理登录及账号相关功能
- 下载、管理、启动应用
- 接受消息推送

## 管控

智通平台本身不具有太多的管控和监视功能，但仍然存在夜间禁用和考试禁用。

### 夜间禁用

夜间禁用的时间取决于学校配置。夜间禁用期间，将无法启动智通平台内**任何应用**，同时若访问已启动的、**做过夜间禁用适配的应用**，将弹出提示并强制关闭。

仅响应、云作业等学海官方应用做过夜间禁用适配。

因此在夜间禁用时段访问**已启动的**其他第三方应用不会受到影响。

### 考试禁用

当云作业内存在正在进行的考试时，即处在考试禁用状态。考试禁用期间，将无法启动智通平台内任何应用，同时若访问已启动的**任何应用**，将弹出提示并强制关闭。

在考试前切断网络连接是没有用的，因为智通平台会根据先前从服务器处获取的**考试时间数据**进行考试禁用。只有在教师布置考试前就切断网络连接，才能规避考试禁用，但你也无法进行考试。
